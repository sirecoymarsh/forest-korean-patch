# Forest(라이어소프트, 2004) 한국어 패치 작업물

비공개 보관용 저장소. 원본 게임 파일·4K 그림(hiart)은 넣지 않았다. 바로 까는 패치 ZIP(한국어 오프닝 영상 포함)은 릴리스에 있다.

| 폴더 | 내용 |
|---|---|
| `qol-and-storymap/` | 통합 DLL(ForestChart.dll) 소스 `native/`: 이야기의 지도 2.0과 편의 기능(화면·진행·단추·4K 글자·4K 그림·되감기). 그 밖에 갈래별 시험 도구·기록, 특전 「오프닝」(`extras-opening-20261125`) |
| `translation-build/` | 번역 반입·대본 빌드 도구, 패치 목록, 검수 기록 |
| `storymap-2.0/` | 이야기의 지도 2.0 모델·도구 |
| `review/` | 깊은 검수·제미나이 검수 목록(스포일러 있음) |
| `assets-ko/` | 게임이 읽는 한국어 덮어쓰기 파일 그대로: 대본 `scr`, 그림 `grpe`·`grpo`·`grps`, 지도 그림·글꼴 `fc` (2026-11-25 놀이 사본에서 복사) |

## 추가·변경 사항

원본 게임(라이어소프트 「Forest」, 2004년, GsWin 계열 엔진) 대비 이 한국어 패치가 바꾸거나 더한 것을 정리했다.
근거는 괄호 안에 파일 이름, 릴리스 태그, DLL 해시 앞자리로 단다. 확실하지 않은 것은 「(추정)」이라고 적었다.

### 대상 판본

- 릴리스 노트에는 「일본어판 Forest 게임 폴더」에 설치한다고 되어 있다(patch-20261125).
- 작업은 2012-01-14 영문 팬패치를 얹은 실행 파일을 바탕으로 했다(`qol-and-storymap/엔진_메모.md`: 「영문 패치+한국어판」, `translation-build/tools/install_build.py`: 「영문 팬패치, 무수정」 격리본). 그래서 노란 음성 자막, Enter로 시간 대기를 끊는 동작 같은 영문 패치의 변경도 한국어판에 들어 있다. 설치 차분이 이 변경까지 함께 담는다(추정).
- 엔진은 한 번에 하나만 뜬다(뮤텍스 `RSCRIPT`).

### 번역 범위

- **원문**: 일본어 원문(대본 `scr/*.gsc`)을 기준으로 옮겼다.
- **노란 음성 자막**: 일본어 대본에 글이 없고 음성만 있다. 그래서 영문 팬패치가 얹은 자막 층을 출처로 하고, 음성을 들어 대조했다(`translation-build/tools/audit_subtitles.py`, `make_review_page.py`, `자막_읽기시간_초과.md`의 714건, `패치15_자막_전건.md`의 43건).
- **번역 빌드(2026-08)**: 번역 맵에서 대본 52개를 다시 만드는 자립 빌더를 두었다(`build_gsc.py`, `rebuild.py`). 교정 패치 76개를 차례로 적용했다(`translation-build/patches/01~76`). 패치에 든 내용은 다음과 같다.
  - 운문·노래: 01·02 운문, 13 해적 노래, 43·57·60 후렴, 47 자장가
  - 이름·고유명사 통일: 05, 10 기노사키, 11, 12 올빼미, 17 아메노모리, 73 히파럼프
  - 같은 원문 같은 번역(에코 통일): 08, 25, 27
  - 정본 용어: 06, 21, 56
  - 수수께끼: 22, 23, 28
  - 노란 자막 검수: 14, 15, 29, 70
  - 오탈자·구두점·전각 정리: 07, 19, 38, 41, 49, 75
  - 줄 폭 재배분: 71, 72. 표시 한계 57폭을 넘는 줄을 글자를 바꾸지 않고 줄바꿈만 옮겼다(`audit_line_width.py`, `rebalance_lines.py`).
  - 개별 오역 고침: 그 밖의 패치들
- **제미나이 재번역과 Claude 검수(2026-11-21~22)**: 제미나이(Antigravity)가 대본을 전면 교정했다. 1차 전면 교정, 2차 인칭·방향·미세 오역 감수 뒤 6차까지 갔다. Claude가 일본어 원문을 기준으로 칸마다 「유지·되돌림·고침」을 판정했다(`review/gemini-review-20261121/`, `data/기준.md`, `재검수_제미나이3차~5차.md`).
- **깊은 검수(2026-11-22)**: 손대지 않은 칸 8,746칸에서 층화 표본 400칸을 뽑아 오류율을 쟀다. minor 이상은 약 4.0%, major는 0.25%였다. 부류 검출기로 지적 187칸을 찾았다. 제미나이 최종 심층 검수를 다시 검수해 확정 541칸을 넣도록 권했다(`review/deep-review-20261122/out/깊은검수_결과_머리.md`, `제미나이_심층검수_재검수.md`). 릴리스 노트에는 「제미나이 재번역 6차 + 깊은 검수 541칸」이 들어갔다고 적혀 있다(patch-20261125).

- **음악 감상 목록(2026-11-23~24)**: 영문 패치 그림 그대로이던 목록 28장(`grpo/3401~3414`, `3501~3514`)을 한국어로 다시 만들었다. 「뒤로」 단추(`grpo/4730`, `4740`)와 특전 세 화면 라벨(`grpe/4004~4006`)도 바꿨다. 원작이 가타카나 외래어인 제목은 한글 외래어로, 일본어 제목은 한국어로, 로마자 제목은 로마자로 두었다. 글꼴은 본명조 Black이다. ### 편의 기능 (원판에 없던 것)

설정은 게임 폴더의 `forest-qol.ini`에서 줄마다 1(켬)·0(끔)으로 바꾼다. `qol=0`이면 편의 기능을 모두 끄고 원작대로 돈다(이야기의 지도는 남는다). 파일이 없으면 기본값(모두 켬)이다(`qol-and-storymap/docs/사용법.txt`, `tools/package.py`).

- **이야기의 지도 2.0**(`storymap-2.0/`, 2026-10-10 Claude가 Codex 1.0을 바탕으로 새로 만듦):
  - 타이틀 「이야기의 지도」 단추, 플레이 중 F8, 아이콘 줄의 갈림길 단추, 창 메뉴로 연다. 지도는 게임 창 안에 그린다. 열린 동안 게임은 멈추고, 닫으면 같은 자리로 돌아간다.
  - 장 I~IX와 「전체」 보기가 있다. 표시는 금빛 = 이번 회차, ✓ = 끝까지 읽음·고른 적 있음, 흐림 = 아직, ？？？ = 아직 닿지 않음이다. 「가린 것 보기」는 화면만 바꾼다.
  - 게임 자체 읽음 기록(`save/rssave.dat`)을 읽어, 지도를 깔기 전에 플레이한 곳도 표시한다.
  - 기록은 `forest-chart-progress`에 따로 저장한다. 원래 세이브는 바꾸지 않는다.
  - **다시보기**: 타이틀에서 연 지도에서 명판·갈림길을 누르면 그 장면을 처음부터 재생하고, 끝나면 지도로 돌아온다.
  - **장 요약(2026-10-15, Codex)**: 다 읽은 장만 두 문장 요약이 열린다(`storymap-2.0/README.md`).
  - 2026-11-23: 2배·3배 창에서 지도가 번쩍이던 것을 고쳤다(`flicker-20261123/`).
  - 2026-11-24: 지도가 느려지던 것을 고쳤다. 3배 창 다시 그리기가 129ms에서 39~40ms가 됐다. 휠 동작도 바꿨다(`fix-20261124/`).
- **Backspace 되감기(2026-11-25)**: 이전 대사로 되감는다. 문장만이 아니라 그 대사가 떴을 때의 그림·음악·음성·노란 자막까지 돌아간다(`native/qol_rewind.cpp`, `s-rewind/조사.md`, DLL 79c70107235b).
  - 누르고 있으면 초당 10걸음씩 계속 뒤로 간다. 선택지로 되감으면 다시 고를 수 있다.
  - 대사 없이 흐르는 소리 자막(311곳)도 한 걸음으로 친다. 되감아 다시 보는 소리 자막은 음성이 끝나도 남아 있다가 클릭·Enter로 넘어간다.
  - 게임을 켠 동안 읽은 300걸음까지 기억한다(`rewind_depth`). 불러오기, 타이틀로 돌아가기, 「직전 선택지로」 단추를 쓰면 거기서부터 새로 쌓인다. 세이브 파일에는 아무것도 넣지 않는다.
  - 원작의 되감기 단추는 직전 체크포인트로 한 단계만 돌아간다(`편의기능_선택.md`).
- **자동 진행 A(2026-11-21)**: 자동 진행 중 누를 때마다 ×1→×2→×3→×4→×5→×1로 바뀐다. 화면 오른쪽 아래에 「자동 ×N」이 표시된다(`native/qol_play.cpp`, `s-play/보고.md`).
  - 기다림은 글 길이에 맞춘다(×1 = 1.2초 + 글자당 0.08초). 음성이 있는 대사는 음성이 끝날 때까지 기다린다.
  - 선택지를 고른 뒤에도 자동 진행이 이어진다. 클릭·Enter로 끈다.
  - 11-25부터 Backspace는 자동 진행 끄기가 아니라 되감기다. 자동 진행 중에 누르면 자동 진행을 끄고 한 걸음 뒤로 간다.
- **Ctrl 읽음 보호**: 설정 「메시지 건너뛰기」가 「읽은 부분만」이면 Ctrl을 누르고 있어도 안 읽은 대사에서 멈춘다. 원작은 Ctrl일 때 읽음을 보지 않았다(`ctrl_protect`).
- **S 바로 저장 / L 불러오기**: S는 가장 최근에 쓴 칸 다음의 빈 칸에 바로 저장하고 「2쪽 왼쪽 셋째 칸에 저장했습니다」처럼 알린다. L은 불러오기 화면을 연다.
- **Home 조작 안내**: 원래 키와 새 키를 한 장에 보여 준다.
- **아이콘 줄 정리**: 아이콘을 상아색으로 밝혔다. 비어 있던 두 칸에 「이야기의 지도」(갈림길)와 「자동 진행」(▷) 단추를 넣었다(`native/qol_buttons.cpp`, `assets-ko/grps/compane.lwg`, `s-buttons/보고.md`).
- **창 크기·전체 화면**(`native/qol_present.cpp`, `s-present/보고.md`):
  - 창 테두리를 끌어 크기를 바꾼다. 4:3은 유지된다.
  - 제목 줄 오른쪽 클릭 메뉴에 「원래 크기·2배·3배·전체 화면」이 있다.
  - 창 자리와 크기를 `forest-qol-window.ini`에 기억한다. 처음에는 화면 높이의 약 2/3 크기로 연다.
- **해설 모드(s-cm)**: 시험판만 있고 통합 소스에는 아직 합치지 않았다(`진행.md` 「11-23 해설 갈래」).

### 화면·그래픽 개선

- **큰 창과 해상도를 바꾸지 않는 전체 화면**: 게임 그림(800×600)을 4:3에 맞춰 검은 띠와 함께 늘린다. 이중선형 보간(SSE2)을 쓰고, 바뀐 곳만 다시 계산한다. 4096×2160 전체 화면에서 평균 5~6ms다(`s-present/보고.md`). 오프닝 영상과 확인 창도 그림 자리 가운데에 맞춘다.
- **4K 글자**(`native/qol_hitext.cpp`, `s-hitext/보고.md`): 큰 창에서 대사, 한 글자씩 찍히는 중, 앞 쪽 다시 보기, 노란 자막(검정 4겹 외곽선 포함), 세이브 화면 날짜를 화면 해상도로 다시 그린다. 엔진 화면은 한 화소도 바꾸지 않고, 창으로 보낼 때만 글자 자리를 바꾼다.
- **4K 그림**(`native/qol_hiart.cpp`, `s-hiart/보고.md`):
  - CG·스탠딩·배경·얼굴 창 705장을 4배로 만들었다(약 1.76GB). Upscayl high-fidelity-4x로 확대한 뒤 원본과 섞고 색을 보정했다.
  - 엔진이 검게 바꿔 그린 스탠딩처럼 지문이 다른 그림에는 4배를 쓰지 않는다.
  - 성적 장면 문맥의 그림 2장(grpe/0024·0025)은 4배에서 뺐다.
  - 「고화질 그림」 꾸러미(`Install-ForestHiresArt.ps1`)로 따로 넣는다. 없으면 원래 그림을 늘려 보여 준다.
- **아이콘 줄 밝기**: 위 「편의 기능」 참고.

### 설치·제거 방식

- **릴리스 patch-20261125(차분판, 원본 게임 파일 없음)**:
  - 게임 폴더에 압축을 풀고 「한국어패치_설치.bat」을 실행한다. `Forest.exe`와 오프닝 영상을 xdelta로 고친다. 한국어 대본·그림·지도·편의 기능 파일을 넣는다.
  - 되돌리기는 「한국어패치_제거.bat」이다.

- **지도·편의 기능 설치기**(`storymap-2.0/tools/Manage-ForestStoryMap.ps1`):
  - `-Mode Verify`, `Install`, `Restore`가 있다.
  - `Forest.exe`(지도 DLL을 부르는 부분만 덧붙임)와 타이틀 대본(단추 하나 추가)을 바꾼다. `ForestChart.dll`, `scr/9000.gsc`, `fc/`, `grps/compane.lwg`, `forest-qol.ini`를 더한다.
  - 바뀌는 두 파일의 원본은 `forest-story-map-backup`에 남는다. 되돌리면 원래 파일 411개가 바이트까지 같아진다(`진행.md`).
  - 한국어판 대본의 명령부가 맞을 때만 설치된다. 일본어 원판에는 설치되지 않는다.

### 알려진 문제

- 고화질 그림 꾸러미는 릴리스에 아직 없다. 「나중에 따로」라고 적혀 있다(patch-20261125). 특전 화면 라벨의 4K 그림 3장(hiart jpg)도 다음 묶음에 넣을 예정이다(`music-titles-20261123/메모.md`).
- 자막이 뜬 대사에서 저장했다가 불러오면 자막이 사라진다. 영문 패치가 글 넣기 대상을 고정 버퍼로 바꾼 탓이다. 환경음(되풀이 효과음)이 깔린 곳에서 불러오면 그 소리가 돌아오지 않는다. 원작 동작이다. 둘 다 고치지 않고 두었다(`진행.md`, `s-rewind/조사.md`).
- 확인 창·알림이 영어로 남아 있을 수 있다(11-21 기록, 위 「번역 범위」).
- 깊은 검수 기준으로 손대지 않은 칸의 약 4~5%에 어색한 번역투·한자음 잔재 같은 minor 결함이 퍼져 있다고 추정된다. 정책 보류 40칸은 검수하지 않았다(`깊은검수_결과_머리.md`).
- 시험하지 못한 것: 되감기 소리를 귀로 듣기, 이야기의 지도 다시보기·특전 장면 회상 중의 되감기(`진행.md`).
- 지도 글꼴 축소본에 ↑·↓ 글자가 없어 대체 글꼴로 나온다(`진행.md`).
- 노란 고해상도 글자 깨짐 신고 장면(2100:285)은 재현하지 못했다. 사용자 화면 확인이 남아 있다.
- 해설 모드(s-cm)는 통합 소스에 합치지 않았다.
