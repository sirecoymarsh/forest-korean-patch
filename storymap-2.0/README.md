## 10-10 오후 수정 — 별도 창 → 게임 창 안
사용자 지적(「지도창이 인게임이 아니라 별도의 창을 여는게 문제」)이 맞았다. 1.0 부터 지도는 스크립트(VM)
스레드가 띄운 별도 팝업 창이었고, 타이틀 단추처럼 스크립트 실행 도중에 열면 게임 창 스레드가 VM 을
기다리며(Sleep 반복) 메시지를 못 받아 「응답 없음」이 되고 X(종료)가 먹지 않았다.
- 지도는 이제 **게임 창 안에 그린다**: 게임 창 프로시저가 그리기·마우스·키를 맡고, 지도가 열린 동안
  게임이 창에 찍는 `BitBlt`/`StretchBlt`(IAT 0x459018/0x45901c)만 건너뛴다.
- 스크립트는 **입력 대기 자리에서만** 멈춘다(`WaitForSingleObject` 가로채기). 타이틀 단추(9000)·F8·창 메뉴는
  요청만 남기고, 다음 입력 대기에서 연다. 그동안 게임 창 스레드는 평소처럼 돈다.
- 지도가 열린 채 X/Alt+F4 → 지도를 닫고 게임의 원래 종료 확인으로 넘긴다. 오른쪽 클릭 = 닫기.
