Forest 편의 기능 + 이야기의 지도

■ 새로 넣은 것
- A : 자동 진행. 켜진 동안 누를 때마다 ×1 → ×2 → ×3 → ×4 → ×5 → ×1. 화면 오른쪽 아래에 「자동 ×N」.
      기다림은 글 길이에 맞추고, 음성이 있는 대사는 음성이 끝날 때까지 기다립니다.
      선택지를 고른 뒤에도 자동 진행이 이어집니다.
      자동 진행은 클릭·Enter 로 끕니다.
- Backspace : 이전 대사로 되감기. 문장만이 아니라 그 대사가 떴을 때의 그림·음악·음성·노란 자막까지 돌아갑니다.
      누르고 있으면 계속 뒤로 갑니다. 선택지로 되감으면 다시 고를 수 있습니다.
      대사 없이 흐르는 소리 자막(노란 자막과 음성)도 한 걸음입니다. 되감아서 다시 보는 소리 자막은
      음성이 끝나도 남아 있다가 클릭·Enter 로 넘어갑니다. 처음 보는 곳부터는 원래대로 저절로 흐릅니다.
      게임을 켠 동안 읽은 만큼(300걸음)만 되돌아갑니다. 불러오기·타이틀로 돌아가기·「직전 선택지로」 단추를 쓰면
      거기서부터 새로 쌓입니다. 세이브 파일에는 아무것도 넣지 않습니다.
      자동 진행 중에 누르면 자동 진행을 끄고 한 걸음 뒤로 갑니다.
- S : 다음 빈 칸에 바로 저장 (「2쪽 왼쪽 셋째 칸에 저장했습니다」처럼 알려 줍니다)
- L : 불러오기 화면
- Home : 조작 안내 한 장 (원래 있던 키와 새 키)
- F8 : 이야기의 지도
- Alt+Enter : 창 ↔ 전체 화면. 전체 화면에서도 모니터 해상도를 바꾸지 않습니다.
- 아이콘 줄: 밝게 바꾸고, 빈 칸 둘에 「이야기의 지도」(갈림길)·「자동 진행」(▷) 단추를 넣었습니다.
- Ctrl 건너뛰기: 설정 「메시지 건너뛰기」가 「읽은 부분만」이면 Ctrl 을 누르고 있어도 안 읽은 대사에서 멈춥니다.
  계속 넘기려면 설정에서 「안 읽은 부분도」를 고르세요.
- 창: 테두리를 끌어 크기를 바꿉니다(4:3 유지). 제목 줄 오른쪽 클릭 메뉴에 「원래 크기·2배·3배·전체 화면」.
  끌 때의 자리·크기를 기억했다가 다음에 그대로 엽니다. 처음에는 화면 높이의 약 2/3 크기로 열립니다.
- 큰 창에서는 대사·화자 이름·노란 자막·앞 쪽 다시 보기의 글자를 화면 해상도로 다시 그려 또렷하게 보입니다.
- 「고화질 그림」 꾸러미(따로, 약 1.76GB)를 넣으면 큰 창에서 CG·스탠딩·배경·얼굴 창도 4배 그림으로 보입니다.
  꾸러미의 Install-ForestHiresArt.ps1 로 넣고 뺍니다. 없으면 그림은 원래 그림을 늘려 보여 줍니다.

■ 원래 있던 키 (게임 설명서에 없던 것 포함)
클릭·Enter·Space 다음 대사 / Ctrl(누르는 동안) 건너뛰기 / Tab 건너뛰기 켜기 / Shift 대화창 숨기기
휠 위·↑ 앞 쪽 다시 보기 / 휠 아래·↓ 다음 쪽 / 오른쪽 클릭 설정 화면 / Esc 열린 화면 닫기
Alt+0~9 1쪽 그 칸에 바로 저장(확인 없이 덮어씀) / Alt+Shift+0~9 1쪽 그 칸 불러오기

■ 켜고 끄기
게임 폴더의 forest-qol.ini 에서 줄마다 1(켬)·0(끔). qol=0 이면 편의 기능을 모두 끄고 원작 그대로 돕니다
(이야기의 지도는 남음). 이 파일을 지워도 기본값(모두 켬)으로 돕니다.
창 자리 기억은 forest-qol-window.ini 에 남습니다(지우면 처음 크기로).

■ 이야기의 지도
- 타이틀 화면의 「이야기의 지도」, 플레이 중 F8, 아이콘 줄의 갈림길 단추, 게임 창 왼쪽 위 메뉴.
- 지도가 열려 있는 동안 게임은 그 자리에서 멈추고, 닫으면(Esc 또는 F8) 같은 자리로 돌아갑니다.
- 금빛 = 이번 회차, ✓ = 끝까지 읽음·고른 적 있음, 흐림 = 아직, ？？？ = 아직 닿지 않음. 「가린 것 보기」는 화면만 바꿉니다.
- 장을 끝까지 읽으면 그 장 요약이 열립니다. 타이틀에서 연 지도에서 명판·갈림길을 누르면 그 장면을 다시 봅니다.
- 기록은 게임 폴더의 forest-chart-progress 에 따로 저장되며, 원래 세이브 파일은 바꾸지 않습니다.

■ 설치·되돌리기 (게임을 끈 뒤 PowerShell 에서)
  검증: .\Manage-ForestStoryMap.ps1 -GamePath '게임 폴더' -Mode Verify
  설치: .\Manage-ForestStoryMap.ps1 -GamePath '게임 폴더' -Mode Install
  되돌리기: .\Manage-ForestStoryMap.ps1 -GamePath '게임 폴더' -Mode Restore
- 설치는 Forest.exe(지도 DLL 을 부르는 부분만 덧붙임)와 타이틀 스크립트(단추 하나 추가)를 바꾸고,
  ForestChart.dll · scr\9000.gsc · fc\ · grps\compane.lwg · forest-qol.ini 를 더합니다.
  (고화질 그림을 넣었다면 되돌리기 전에 그 꾸러미의 Restore 로 hiart\ 를 먼저 빼세요.)
  바뀌는 두 파일의 원본은 forest-story-map-backup 에 남고, 되돌리면 원래 그대로가 됩니다(세이브는 그대로).
- 한국어판 스크립트의 명령 부분이 맞으면 설치됩니다. 번역 문구만 고친 판은 그대로 쓸 수 있습니다.
