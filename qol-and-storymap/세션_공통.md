## 시험 규칙(사용자 결정)

- 게임 창은 **화면 밖**(모든 모니터 오른쪽 바깥 등)·**소리 없이**·대화 상자도 화면 밖으로 띄우고, 끝나면 게임이 바꾼 창 위치(레지스트리 등)를 되돌린다. 사용자 마우스·키가 시험 창에 섞이지 않게 한다. 사용자 조작 흔적(엉뚱한 클릭 등)이 보이면 자동 조작을 멈춘다.
- 창이 비활성이면 엔진이 멈춘다 → WM_ACTIVATEAPP(1)+WM_ACTIVATE 를 PostMessage. 캡처는 PrintWindow(flag 2). 도구: `P:\AI\forest-flowchart-claude\tools\gamectl.ps1`·`waitshot.ps1`·`quitgame.ps1`(읽고 자기 사본 경로로 고쳐 써도 된다).
- 강제 종료만 하지 말고 **정상 종료**(종료 확인 「예」)까지 본다. 새 기능은 「다녀온 뒤 다른 부분이 안 깨지나」까지 본다(지도 열고 닫기, 세이브·불러오기, 설정 화면, 대화창 숨기기).
- Forest 가 두 번째 실행을 막을 수 있다(뮤텍스 가져오기 있음, 미확인). 막히면 다른 시험 사본의 Forest 가 꺼질 때까지 기다렸다 띄운다.
- 사용자는 III장(2300) 언저리를 플레이 중이다. 시험 화면·보고에 그 뒤 이야기를 담지 않는다(세이브는 사본의 것을 쓰고, 뒤 장면 문구를 보고에 옮기지 않는다).

## 만들 때 지킬 것(사용자 원칙)

- 새 화면·문구는 게임 UI 의 형제처럼(지도 2.0 의 양피지·담쟁이 틀, 글꼴 `fc\ForestChartSerif-*.ttf` — 한글 2,583자 축소본이라 쓴 글자가 다 있는지 확인).
- 쉬운 한국어 UI 말(일본식 한자어·개발 용어 금지). 상태를 그대로 말한다.
- 기능마다 `forest-qol.ini` 한 줄로 끈다(`qol::Cfg("키", 기본값)`). 세이브에 흔적을 남기지 않는다.
- 버벅이지 않게(사용자: 「그게 제일 중요해」). 원작 키와 겹치지 않게, 조합키 쓰지 않음.
- 한글 입력기가 켜져 있으면 글자 키가 VK_PROCESSKEY 로 온다 → `ImmGetVirtualKey`(하늘색 풍금에서 겪음).
