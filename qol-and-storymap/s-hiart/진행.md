## 엔진 근거(이 갈래가 확인)

- 층 50개 `[0x466238+i*4]`(객체 0x364). 층 바탕 S = 층+0x2a4: +0xc 보임, +0x1c/+0x20 자리, +0x30(0/6, 6 = 불투명 복사 길 0x42fc60 — 어둡게 하기 아님).
- 그릇 = 층+0x54(썽크 `sub ecx,[ecx-4]; sub ecx,0x250`): 자식 배열 [층+0x30](12바이트 칸), 개수 u16 층+0x34(늘 3), z 색인 [층+0x38]. 보이는 자식은 그림 하나뿐.
- 그림 객체 I = [층+0x50], 바탕 SI = I+4+[[I+4]+4](그림 0x4c, 스탠딩 0x74): +4 화소, +0xc 보임, +0x14/+0x18 크기, +0x28 섞기(그림 0), +0x3c 사각형.
- 엔진 화소: BGRA, **알파 바이트 = 255 − a(투명도)**, 불투명 색은 PNG 와 같음, 반투명 화소 색은 꺼내기 도구 PNG 가 조금 다름(미리 곱하기 왕복 손실) → 1배 모형은 엔진 화소 복사본으로.
- 층 그림은 0x4069d0(thiscall 경로·인자 → [층+0x50]->vf60)으로만 바뀐다(타이틀·세이브 불러오기 포함).
- 합성: 검정 바탕 위 번호 순, (s·a + d·(255−a))/255 와 ±2.
- 어둡게 그리는 장면(II장 회상 0.5, III장 첫머리 0.71)의 세기는 층 칸에 없다 → 안정된 화면에서 원본 → 화면 채널별 k·x+b 를 맞춰 씀(이상값 빼고 두 번 같은 값일 때).
- 전환: 엔진은 옛 화면(+0xa4)과 새 합성을 화면 전체 같은 t 로 섞음. 장면 0.05 단계(약 330ms), 스탠딩·얼굴 창 0.1 단계(약 160ms). 4K 글자 갈래 조사(`s-hitext\조사.md`)와 같음.

## 모듈 방식

찍기마다(PaintAbove, 화면 잠금 안): 층 상태 → 1배 모형(상태마다 한 번) ↔ 그림자 판 화소마다 비교 → 지금 / 바로 앞 / t 섞기(바뀐 화소 1000↑, 90%↑ 일치) 판정 → 3×3 깎기(외딴 우연 일치 제거) → 4배 합성(상태마다 물리 크기 줄 캐시, WIC HighQualityCubic 로 창 배율에 맞춰 줄인 PBGRA) 으로 그 화소만 덮음. 안 맞는 곳은 늘린 1배 그대로.
