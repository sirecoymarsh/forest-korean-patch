## 3. 후보별 자세히

### 1. 자동 진행 + 배율 ×1~×5 + 음성 끝까지 — 넣기

- **하는 일**: A 키나 아이콘 단추로 자동 진행을 켭니다. 켜진 동안 A 를 누를 때마다 ×2→×3→×4→×5→×1. 아이콘 줄 옆에 「자동 ×N」. 음성이 있는 줄은 음성이 끝난 뒤 넘어갑니다. 끄기는 클릭·Enter(원작 동작 그대로).
- **지금은**: 엔진에 자동 진행이 있습니다. 하지만 켤 길이 없습니다. [확인]
  - 엔진은 아이콘 줄 단추 8개를 그림 층 이름으로 만드는데, Forest 그림 `compane.lwg` 에는 `auto` 층이 없습니다. 키 표에도, 설정 화면에도 없습니다.
  - 엔진의 자동 진행은 글이 다 찍힌 뒤 **1초를 쉬고 음성이 끝날 때까지** 기다립니다(`0x41c70a` `Sleep(1000)` → `0x41c715` 음성 채널 대기 `0x43f690(1)`). 음성 없는 긴 글도 1초 만에 넘어갑니다. (11-21 바로잡음: 처음엔 「음성을 안 기다린다」고 적었습니다.)
- **이득**: 큼. 음성 대사가 5,677줄입니다.
- **갈고리**:
  - 켜기·끄기: 엔진의 자동 콜백 `0x4166d0`(`[0x466408]=1`)을 게임 스레드에서 부릅니다. 클릭·Enter 로 꺼지는 길은 원작에 있습니다(`0x415603`).
  - 글 길이에 맞춘 대기: `Sleep(1000)` 한 자리만 바꿔 읽는 시간을 글자 수로 셈하고 배율로 나눕니다. 음성 끝까지 기다리는 엔진 단계는 그대로 둡니다.
  - 아이콘·「×N」 표시: 5와 함께. 글자는 지도 DLL 이 이미 쥔 창 그리기 갈고리로 얹습니다.
- **품**: 중간.
- **함께 고를 것**: 선택 뒤에도 자동 진행 계속(`auto-continue-after-choice`). 엔진은 선택 처리 쪽에서 자동을 끕니다(`0x41e054`·`0x41d7fd` [추정]). 선택지가 101개뿐이라 이득은 작습니다.

### 2. Ctrl 건너뛰기도 「읽은 부분만」을 따름 — 넣기

- **하는 일**: 설정이 「읽은 부분만」이면 Ctrl 을 누르고 있어도 안 읽은 줄에서 멈춥니다. 다시 넘기려면 Ctrl 을 뗐다 다시 누릅니다. 설정이 「안 읽은 부분도」면 지금과 같습니다.
- **지금은**: 읽음 검사가 Tab·» 건너뛰기에만 걸리고 Ctrl 에는 안 걸립니다. [확인] `0x41c9ec`: `[0x466404]`(Tab·»)일 때만 읽음 함수 `0x418d90` 를 부릅니다. Ctrl 은 `[0x466400]` 이라 지나칩니다.
- **이득**: 중간. 지금 첫 회차 중(III장 언저리)이라 Ctrl 을 잘못 누르면 처음 보는 글을 날립니다.
- **갈고리**: 지도 DLL 의 명령 읽기 갈고리(`0x41a240`)에서 대사 명령이고 Ctrl 상태이면 읽음 함수를 불러 보고, 안 읽었으면 Ctrl 깃발 `[0x4663f8]` 을 내립니다.
- **품**: 작음.

### 3. S = 다음 빈 칸에 바로 저장 · L = 불러오기 화면 — 넣기

- **하는 일**: S 를 누르면 칸 고르는 화면 없이 가장 앞의 빈 칸에 저장하고 「12번 칸에 저장했습니다」를 잠깐 띄웁니다(사용자 표준, 10-27). L 은 불러오기 화면을 엽니다. Q(빠른 저장 전용 칸)는 원하실 때만.
- **지금은**: 저장은 오른쪽 클릭 → 저장 → 칸 → 확인 창으로 네 번 누릅니다. 숨은 키 Alt+0~9 는 1쪽 0~9번 칸에 **확인 없이 덮어씁니다**(설명서 밖).
- **이득**: 중간. 지금 세이브 14칸을 쓰고 계십니다.
- **갈고리**: 저장은 Alt+숫자가 부르는 엔진 함수 `0x418a80(칸 번호)` 를 그대로 씁니다. 빈 칸은 `save\rssave00~99.dat` 가 있는지로 찾습니다. 입력 대기 중에만 받습니다(장면 전환 중 저장 막기).
- **품**: 작음.
- **정할 것**: 원작 숨은 키 Alt+숫자(확인 없이 덮어쓰기)를 그대로 둘까요? 권고는 그대로(원작 기능).

### 4. 창 크게 · 해상도를 안 바꾸는 전체 화면 · 창 자리 기억 — 넣기

- **하는 일**:
  - 창 크기를 끌어서 바꾸거나 2배·3배로 고릅니다. 4:3 을 지키고 남는 곳은 검게 둡니다.
  - Alt+Enter 와 원작 설정의 「전체 화면」을 **테두리 없는 전체 화면**으로 바꿉니다. 모니터 해상도는 그대로 둡니다.
  - 끌 때 창 자리·크기·전체 화면 여부를 적어 두었다가 다음에 그대로 엽니다.
- **지금은**: 800×600 고정 창입니다. 전체 화면은 `ChangeDisplaySettingsA` 로 **모니터 해상도를 800×600 으로 바꿉니다** [확인 가져오기 표]. 주 모니터가 4096×2160 TV 라 바꿀 때마다 TV 가 화면을 다시 잡고 다른 창이 흐트러집니다. 실행 파일에 고해상도 선언이 없어서, 윈도 배율이 100% 가 아니면 윈도가 흐리게 늘립니다 [확인: 매니페스트 없음].
- **이득**: 큼.
- **갈고리**: 지도 DLL 이 이미 게임의 창 그리기(`BitBlt`/`StretchBlt`, 가져오기 칸 `0x459018`/`0x45901c`)를 쥐고 있습니다. 800×600 그림을 창 크기로 늘려 찍고, 마우스 좌표는 되돌려 셉니다(게임은 마우스를 창 메시지로만 받습니다, 해설 연구 F5). 지도 화면도 같은 배율로 늘려야 합니다.
- **품**: 중간.

### 5. 아이콘 줄 정리 — 넣기(1과 함께)

- **하는 일**: 대화창 아래 아이콘 줄을 상아색으로 밝히고, 빈 칸 둘에 **자동** 단추와 **지도** 단추를 넣습니다. 10-10 시안 `forest-flowchart-claude\out\mock_compane.png` 가 이것입니다(그때 답 대기).
- **지금은**: 단추 6개(되감기·앞 쪽·다음 쪽·건너뛰기·음성·숨기기)와 글자 속도 슬라이더. 평소에 흐려서 잘 안 보입니다(사용자 10-10 「게임 기본 아이콘은 지금도 잘 안보이네」).
- **갈고리**: 엔진이 `auto`·`menu` 칸을 층 이름으로 만들고 콜백도 걸어 둡니다(`0x40fab1`~, `0x414de2`~). 그림 층만 더하면 그리기·마우스 올림·숨김은 엔진이 합니다.
  - 주의: `menu` 칸의 콜백(`+0x2c8c`)은 **오른쪽 클릭도 부릅니다**(`0x410b90`). 콜백을 통째로 지도로 바꾸면 오른쪽 클릭이 설정 화면 대신 지도를 엽니다. 단추를 누른 경우만 가려내야 합니다.
- **품**: 작음(그림은 코덱스 몫).
- **정할 것**: 빈 칸은 둘뿐입니다. 자동·지도로 쓰면 해설 모드 단추는 DLL 이 줄 옆에 따로 그려야 합니다(5절).

### 6. 조작 안내 한 장(Home) — 1·3을 넣으면 함께

- **하는 일**: Home 을 누르면 모든 키를 한 장에 보여 줍니다. 원작 숨은 키(Tab·Shift·휠·Alt+숫자)와 새 키(A·S·L·F8)를 같이 적습니다. 지도와 같은 틀로 게임 창 안에 그립니다.
- **지금은**: 게임 안에 키 안내가 없습니다.
- **품**: 작음.

### 7. 4K 글자 — 결정해 주세요

- **하는 일**: 4로 창을 키운 뒤, 대사 글자만 화면 해상도에 맞는 큰 글꼴로 다시 그립니다. 그림은 그대로 늘립니다(사용자 원칙 「고화질은 글자 먼저」).
- **지금은**: 800×600 글을 늘리므로 흐립니다.
- **갈고리**: 엔진은 GDI 로만 그립니다(해설 연구 F3). 글자를 찍는 GDI 호출을 가로채 줄과 자리를 받아 두었다가 확대할 때 다시 찍습니다 [시험 필요]. 노란 자막의 외곽선 5겹, 한 글자씩 찍히는 효과, 앞 쪽 다시 보기까지 맞춰야 합니다.
- **품**: 큼. 4가 먼저 있어야 합니다.

### 8. 대화 기록 화면 — 결정해 주세요(해설 모드와 함께 권함)

- **하는 일**: 지난 대사를 한 화면에 여러 줄 보입니다. 줄마다 ▷ 음성, 「이 줄로 돌아가기」(여러 단계).
- **지금은**: 휠 위로 대화창 안에서 한 쪽씩 앞을 봅니다(최근 100줄). 되감기는 한 단계뿐입니다. 그래서 이득은 「한눈에 보기 · 여러 단계 돌아가기 · 지난 줄 음성」 셋입니다.
- **갈고리**:
  - 줄 목록: 엔진 자신의 100줄 표를 읽습니다(항목 0x70바이트에 대본 번호·슬롯, `0x410690`).
  - 돌아가기: 엔진의 되감기 길(`0x416640`: 체크포인트 되돌리기 → 화면 다시 부르기 `0x43d910`)을 빌립니다. 엔진이 줄마다 만드는 체크포인트(`0x418a40`)를 DLL 이 줄마다 떠 두었다가, 고른 줄의 것을 「직전 체크포인트」 칸에 넣고 되감기를 누릅니다 [시험 필요: 그림·음악이 따라오는지].
- **품**: 큼.

### 9. 게임 안 문장 검색·고치기 — 기본값이라 골라 둠, 시기는 결정해 주세요

- **하는 일**: 게임 안 메뉴에서 장면·문장을 찾고, 지금 줄을 그 자리에서 고치고, 이력을 보고 되돌립니다(사용자 기본값 10-24).
- **지금은**: 오역 신고기가 화면과 메모를 보내면 세션에서 고칩니다. 남은 오역 교정은 제미나이가 `runtime` 사본에서 하고 있습니다.
- **갈고리**:
  - 지금 줄 = 명령 읽기 갈고리의 (대본, 슬롯) [확인, 해설 연구 F1].
  - 고친 글은 「슬롯 → 문자열」 함수 `0x413080` 을 가로채 덧씌움 표에서 내줍니다. 대본을 다시 빌드하지 않아도 바로 화면에 나옵니다.
  - 「반영」은 `forest-kr-build` 패치 꼴로 내보냅니다. 제미나이·`rebuild.py` 사슬과 갈라지지 않게 하려는 것입니다. 토큰(`^g###`·`^n`)·줄 폭 57·조사 검사도 같이 겁니다.
- **품**: 큼(한글 입력 칸, 이력·되돌리기, 내보내기).
- **정할 것**: 제미나이 교정이 들어온 뒤에 할까요? 권고는 「뒤에」(같은 대본을 두 쪽에서 고치면 갈라집니다).

### 10. 다른 창을 봐도 자동 진행은 계속 — 결정해 주세요

- **하는 일**: 다른 창으로 가도 자동 진행은 이어지고 건너뛰기만 멈춥니다(사용자 원칙 4).
- **지금은**: 엔진이 창을 떠나면 그리기 타이머를 세워 모든 것이 멈춥니다(`0x43dfab`). 건너뛰기 멈춤은 이미 됩니다.
- **갈고리**: 창을 떠날 때 엔진이 받는 「비활성」 알림을 자동 진행 중에만 삼키고, 건너뛰기 깃발은 우리가 내립니다(지도 시험 요령 「WM_ACTIVATEAPP」과 같은 길).
- **품**: 중간. 1이 있어야 뜻이 있습니다.

### 11. 새 기능 설정을 한 곳에(F1) — 셋 이상 고르면

- 자동 배율 처음 값, 창 배율, Ctrl 읽음 보호, 자동 계속 같은 켜기·끄기를 원작 설정 화면 꼴로 한 장에 둡니다. F1 은 엔진이 개발용 함수를 부르는 자리이고 출고판에선 비어 있습니다[추정, `0x419020`].
- 둘 이하면 설정 파일 한 줄씩으로 충분합니다.

### 12. 세이브 자동 백업 — 3을 넣으면 함께(선택)

- 켤 때마다 `save\` 를 날짜별로 몇 벌 떠 둡니다. 바로 저장(3)과 숨은 Alt+숫자 덮어쓰기에 대한 보험입니다. 이득은 작습니다.

## 6. 곁가지로 찾은 것(편의 기능이 아니라 번역 누락)

1. **확인 창이 영어입니다.** 덮어쓰기·불러오기·타이틀로·종료 확인 창과 알림·오류 문구가 영문 패치 실행 파일의 영어 그대로입니다(`Forest.exe` 파일 위치 0x6a000~0x6a680: 「Overwriting save data.」 「Do you really want to quit?」 등). 원작은 일본어였습니다(「セーブデータを上書きします。」 등). 고치기는 작습니다(문자열 칸 바꾸기, 또는 DLL 이 확인 창 문구를 바꿔 끼우기).
2. **특전 음악 감상 목록 그림 28장이 영어입니다.** `grpo\3401~3414.wcg`(평소)·`3501~3514.wcg`(올림)가 영문 패치 그림과 바이트가 같습니다(첫 줄 「1. Garden」). 원작은 일본어(「1, ガーデン」)입니다. 그림 일이라 코덱스 몫입니다.
3. **지도 2.0 은 아직 플레이 사본에 없습니다.** 시험 실행본에만 있습니다. 위 기능들도 같은 DLL 에 넣을 생각이라, 플레이 사본 설치를 그때 함께 하시면 됩니다.

## 7. 만들 때의 틀(고르신 뒤)

- **DLL 하나에.** 지도 2.0 의 `ForestChart.dll` 이 이미 명령 읽기·입력 대기·창 그리기·창 프로시저를 쥐고 있습니다. 새 기능도 여기에 넣고, 기능마다 설정 파일 한 줄로 끄게 합니다(기능 빼기 시험·속도 비교에도 씁니다). 세이브에는 흔적을 남기지 않습니다.
- **사본.** `runtime`(제미나이 교정 중)과 `forest-kr-build\game`(사용자 플레이)은 건드리지 않습니다. 따로 뜬 사본에서 만들고, 화면 밖·소리 없이 시험합니다.
- **그림.** 아이콘 줄 그림(후보 5)과 특전 목록 그림(6절 2)은 코덱스에 넘깁니다.
- **시험.** 지도 때처럼 열고 닫기 전후 VM·변수·스택 감사(`AUDIT PASS`), 정상 종료까지 봅니다. 「테스트해 줘」는 다녀온 뒤 다른 부분이 안 깨지는지까지입니다.
